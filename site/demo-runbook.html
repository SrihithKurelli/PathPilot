Evaluation-day procedure

Live emulated network demo

This demonstrates the running Ryu controller with OpenFlow 1.3, Open vSwitch, and Mininet. It is a network emulation running on Linux.

!
Do not overlap it with another Mininet campaign.

The campaign and demo share Mininet/OVS state. Wait for the active WSL campaign to finish before starting this demo.

Before starting

Check the environment

  • Ubuntu 22.04 or WSL2 with Mininet, Open vSwitch, iperf3, and the project Python environment installed.
  • Open two terminals at the PathPilot repository root.
  • Confirm no campaign or other Mininet topology is running.
  • Keep the deployed results dashboard open for comparison with the saved campaign evidence.

Terminal 1

Start the Ryu controller

From the repository root, activate the project environment and run:

source .venv/bin/activate
PYTHONPATH="$PWD" EVENTLET_NO_GREENDNS=yes ryu-manager controller/ryu_app.py

Wait for the switches to connect and for live port telemetry to appear in the controller log.

Terminal 2

Start Mininet and check connectivity

From the repository root:

sudo env PYTHONPATH="$PWD" /usr/bin/python3 topology/mininet_topology.py --controller 127.0.0.1 --port 6653

At the Mininet prompt, inspect the topology and verify connectivity:

nodes
net
pingall
links

Proceed only after the hosts can reach one another and the expected paths are visible.

Controlled experiment

Show an actual path decision

For a repeatable measured demonstration, exit Mininet and stop the manually started controller first. Then run the small balanced experiment from the repository root:

source .venv/bin/activate
sudo env PYTHONPATH="$PWD" /usr/bin/python3 experiments/run_balanced_path_matrix.py --trials 1 --conditions baseline --output-dir results/demo_smoke

Open the generated CSV and controller log. Show the selected path, connectivity result, and measured throughput. This is a smoke demonstration; use the 599-trial dashboard for repeated performance comparisons.

Close cleanly

Stop the demo

  1. Exit Mininet with exit.
  2. Stop Ryu with Ctrl+C.
  3. Check OVS state before cleaning anything. Avoid deleting bridges or processes belonging to other work.
