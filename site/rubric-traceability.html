System design and implementation

  • SDN system: Ryu OpenFlow 1.3 controller, Mininet topology, and Open vSwitch switches.
  • Topology: two alternate paths between ingress and egress switches, with controllable link capacity and impairments.
  • Policies: static, least-loaded, threshold, stability-aware, and uncertainty-aware new-flow selection.
  • Telemetry and rules: OpenFlow port statistics, path decisions, and installed flow rules are recorded by the prototype.

End-to-end integration and deployment

  • Automated integration: the repository Mininet/Ryu CI smoke workflow passed on the deployment branch.
  • Hosted evidence: the interactive results site is deployed with the 599-trial filtered dataset.
  • Live demonstration: the local Ryu + Mininet procedure is in the demo runbook. Run it separately from an active campaign.
  • Scope: Mininet/OVS is an emulated deployment; the project does not claim a physical production-network deployment.

Performance evaluation and limitations

  • The prior campaign planned 600 trial cells. The strict audit passed 599; one link-loss recovery cell is excluded because the impairment command failed during link restoration and its recovery time was not measured.
  • The dashboard presents TCP application RTT p99, goodput, UDP loss where UDP traffic exists, fairness where flows compete, path changes, and controller CPU/RSS. Unsupported metrics are hidden for a filter slice.
  • None of the 12 preregistered combined-telemetry burst comparisons met every guardrail. The p99 goal was missed in 11/12; the path-change objective was missed in 9/12.
  • The uncertainty-aware policy is a prototype heuristic. These results do not establish a novel algorithm or a universal winning policy.

Presentation evidence to show

  1. Explain the topology, controller, telemetry, and route-selection question.
  2. Run the live emulated demo and show a real controller decision.
  3. Use the dashboard to compare policies within one scenario, telemetry condition, and initial path.
  4. State the excluded trial, thresholds not met, and emulation limits clearly.
