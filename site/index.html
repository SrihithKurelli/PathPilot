What is measured

Network behavior, not a mockup

The experiment runs a Ryu SDN controller with OpenFlow and Open vSwitch inside Mininet. Workloads exercise steady traffic, bursts, mixed flows, degradation, loss, and link recovery with baseline or delayed/noisy telemetry.

Primary latency is TCP application RTT p99 from a dedicated echo probe during concurrent traffic. Goodput, UDP loss, Jain fairness, path changes, FlowMods, telemetry overhead, and controller CPU/RSS provide supporting outcomes.

Data integrity

599 included · 1 excluded

The source campaign planned 600 trials. One link_loss_recovery / combined / s1-s3-s4 / uncertainty_aware / rep 001 cell was excluded because an impairment command failed during link restoration; its recovery timestamp and measured outage duration are missing.

The remaining 599 cells passed the strict per-trial artifact checks. This filtered subset is not described as a clean 600-trial audit. Raw source records remain preserved separately.

How to read it

Intervals and limits

Summary intervals are trial-level bootstrap 95% intervals, stratified by scenario, telemetry condition, initial bottleneck path, and policy. Paired comparisons match workload seeds across policies. Preregistered guardrails are reported as met, not met, or incomplete; no threshold is changed after seeing results.

Mininet is an emulation. These results do not establish production carrier-network performance, and the uncertainty-aware policy is evaluated as a project prototype rather than a proven novel algorithm.
